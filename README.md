# أدوات الوظائف - JobTools (Full-Stack Resume & JD Generator)

منصة متكاملة لإنشاء السير الذاتية باللغتين العربية والإنجليزية وتوليد الوصف الوظيفي لجميع المهن احترافيًا، مدعومة بالكامل بالذكاء الاصطناعي الآمن عبر خادم وراء الكواليس.

---

## الميزات الرئيسية (Core Features)

1. **مولد السيرة الذاتية باللغة العربية (ATS-Compliant Arabic CV Generator)**:
   - إنشاء سيرة ذاتية عربية احترافية خضراء لفرز الأنظمة الآسيوي والخليجي.
   - خيار تحسين الصياغة والأداء بالذكاء الاصطناعي (OpenAI).

2. **مولد السيرة الذاتية باللغة الإنجليزية (English CV Optimizer)**:
   - صياغة سيرة ذاتية إنجليزية معيارية بأسلوب غربي مميز.
   - تحسين المهام والصياغات لأفعال قيادية قوية عبر الذكاء الاصطناعي.

3. **مولد الوصف الوظيفي لجميع المهن (Professional Job Specs Fabricator)**:
   - بناء بطاقات وصف وظيفي متناسقة تشمل المسمى، القسم، الخلاصة، المسؤوليات، المتطلبات، والمهارات.

4. **خيارات التوليد المزدوجة (Dual Options)**:
   - **توليد عادي (Front-end only)**: يعمل محليًا بالكامل بدون استهلاك الـ API وصياغة نموذجية مدمجة.
   - **توليد بالذكاء الاصطناعي (AI Generation)**: ينقل البيانات بشكل آمن لمنظومة الباك إند ويطلب ترقية وتعديل احترافي من OpenAI GPT-4o-mini ثم يستبدل الحقول ويرسمها مباشرة في المعاينة.

5. **أمن وحماية مفاتيح API (Security First)**:
   - إخفاء تام لمفتاح OpenAI API عن المتصفح وصناديق الـ Console، والاعتماد بالكامل على خادم مؤمن.
   - تحميل مباشر لـ PDF ونسخ نصوص منظم.

## طريقة التشغيل محلياً (How to Run Locally)

تطوير المشروع ودمج الواجهات يعتمد على بنية **Unified Express + Vite**، مما يمكن من تشغيل الخادم والواجهات معًا بأمر تشغيل أحادي أو تفرع ثنائي مرن:

### الخيار 1: الخادم الموحد والسهل (Unified Express + Vite - Port 3000)
وهي الطريقة المفضلة للمنصة، حيث يقوم Express باحتضان Vite في بيئة محلية واحدة:

1. قم بتهيئة ملف المتغيرات `.env` في المجلد الرئيسي بإضافة مفتاح الـ API الخاص بـ OpenAI:
   ```env
   OPENAI_API_KEY=sk-proj-EUJexchGvv...
   ```
2. تثبيت الحزم المطلوبة:
   ```bash
   npm install
   ```
3. تشغيل وضع التطوير الموحد:
   ```bash
   npm run dev
   ```
4. افتح المتصفح على: `http://localhost:3000`

---

### الخيار 2: التشغيل المنفصل (Separate Front-end & Backend)
إذا رغبت في عزل الباك-إند في منفذ منفصل (Port 3001) والواجهة في منفذ منفصل:

**الواجهة الأمامية (Vite Frontend):**
```bash
# تشغيل خادم الواجهات فقط
npx vite --port 3000
```
تفتح على `http://localhost:3000`

**الخلفية والأمان (Express Backend - Port 3001):**
تأكد من وجود مفتاحك في ملف `.env` في المجلد الرئيسي ثم قم بتشغيل خادم الباك إند:
```bash
# تشغيل خادم الباك إند المستقل بالاعتماد على TSX
npx tsx server.ts
# أو بتخصيص منفذ منفصل
PORT=3001 npx tsx server.ts
```
عندها ستتعرف واجهات المولد تلقائيًا على المنفذ `3001` عند العمل على localhost وتقوم بعمل التحسينات الذكية مباشرة!
